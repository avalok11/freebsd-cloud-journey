# Фаза 1 — FreeBSD актуальный: сеть, ZFS, базовый сервисный SSH

**Статус:** запланирована
**Плановый период:** август 2026
**Цель фазы:** уверенная работа с сетью и ZFS на актуальной FreeBSD, понимание отличий от Linux, настроенная сервисная SSH-учётка для ZFS-репликации.

## Что войдёт в отчёт по завершении фазы

- [ ] PF (Packet Filter) с базовым набором правил
- [ ] ZFS-пулы, датасеты, snapshot/clone
- [ ] ZFS send/receive на вторую ноду через сервисный ssh-ключ
- [ ] Шифрованный dataset
- [ ] Сервисный пользователь `zfs-repl` с `forced-command` в authorized_keys
- [ ] Тест failover репликации
- [ ] Сравнение с Linux (ext4+LVM, btrfs)

## Артефакты

- `phase-1-zfs-report.md` — отчёт о результатах ZFS-тестов
- `pf-ruleset.conf` — базовый набор правил PF с комментариями
- `zfs-replication.sh` — скрипт репликации, готовый к интеграции в Ansible
- `service-ssh-setup.md` — документация по сервисной SSH-учётке

Подробности — в [`../roadmap.md`](../roadmap.md).
